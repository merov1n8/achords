# ADR-0019: Default MCP catalog

Status: Accepted (2026-11-19)

- Decision: Google Ads, Analytics, Search Console, AdMob, Google Cloud/Firebase, Meta (FB/IG), TikTok, Reddit, App Store Connect, Google Play Console, WordPress, ElevenLabs, fal.ai, Meshy, Gmail/Calendar/Drive, Unity MCP.
- Consequences: Google Ads API developer token approval should be requested early.
