# Privacy Policy

Last updated: 2026-11-20

achords is self-hosted software. Each installation runs on its owner's own computer and is operated only by that owner.

## Google user data

When the owner connects a Google account (Google Analytics, Search Console), achords requests read access to that account's data through Google's official APIs.

- Data is used only to show reports and generate marketing insights for the owner inside their own installation.
- Data and OAuth tokens are stored locally on the owner's machine, encrypted. They are never sent to the achords developers or any server operated by them.
- Data is not sold, shared with third parties, or used for advertising.
- If the owner chooses a cloud AI model for a task, the relevant data is sent to that model provider under the owner's own account and settings. Data marked local-only never leaves the machine.

achords' use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Disconnect Google in the achords settings, or revoke access at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Deleting the installation deletes all stored data.
